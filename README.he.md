<h1 align="center">Mad Reader</h1>

<p align="center" dir="rtl">קורא Markdown מהיר ויפה ל-Windows, עם תמיכה מלאה בעברית ובכתיבה מימין לשמאל.<br>

<div dir="rtl">

Mad Reader פותח קובצי `.md` במהירות. זהו קובץ הפעלה יחיד בגודל של כ-4MB, שנפתח תוך פחות משנייה. הוא מציג את המסמכים כמו GitHub, בפריסה נוחה לקריאה, **ומטפל נכון בעברית, פסקה אחרי פסקה**. אפשר להגדיר אותו כאפליקציית ברירת המחדל לקובצי Markdown.

## תכונות

- **כיווניות נכונה.** הכיוון נקבע לכל פסקה, פריט ברשימה, כותרת, תא בטבלה וציטוט בנפרד. משפט בעברית שמתחיל במילה באנגלית (למשל "React היא ספרייה…") יוצג מימין לשמאל. קוד מוצג תמיד משמאל לימין. במסמך בעברית תוכן העניינים עובר לצד ימין. אפשר לכפות כיוון אוטומטי, RTL או LTR עם <kbd>Ctrl</kbd>+<kbd>D</kbd>.
- **חיפוש שמבין עברית.** החיפוש (<kbd>Ctrl</kbd>+<kbd>F</kbd>) מתעלם מניקוד, כך ש"בראשית" ימצא גם "בְּרֵאשִׁית".
- **קידודים ישנים.** קבצים ב-UTF-8, ב-UTF-16 ובקידוד העברי הישן Windows-1255 מוצגים כראוי.
- **Markdown בסגנון GitHub.** טבלאות, רשימות משימות, הערות שוליים, תיבות התראה (`> [!NOTE]`), הדגשת תחביר לכ-150 שפות וכפתור העתקה לכל בלוק קוד.
- **נוסחאות, תרשימים וגרפים.** נוסחאות LaTeX (`$…$`, `$$…$$`) מוצגות בעזרת KaTeX. בלוקים מסוג `mermaid` מוצגים כתרשימים וגרפים של נתונים, ובלוקים מסוג `dot` מסודרים בעזרת Graphviz. כולם מתאימים את עצמם לערכת הנושא ועובדים בלי חיבור לאינטרנט.
- **עדכונים אוטומטיים.** בדיקה שקטה פעם ביום מול GitHub. בלחיצה אחת הגרסה החדשה יורדת, נבדקת, מותקנת, והמסמך נפתח מחדש. אפשר לכבות את הבדיקה.
- **ממשק בעברית.** התפריטים, הכפתורים, החלונות והמדריך זמינים בעברית, והממשק כולו מוצג מימין לשמאל. ברירת המחדל היא לפי שפת Windows, ואפשר לבחור בתפריט **Aa ← שפה**.
- **רענון חי.** כשעורכים את הקובץ בכל עורך, התצוגה מתעדכנת עם השמירה ושומרת על מיקום הקריאה.
- **נוחות קריאה.** ערכות נושא בהירה, ספיה וכהה (או לפי Windows), גופן עם או בלי תגים, גודל טקסט, ריווח שורות, רוחב עמוד ויישור לשני הצדדים. כל ההעדפות נשמרות.
- **ניווט.** תוכן עניינים שעוקב אחרי מיקום הקריאה, קישורים בין קובצי Markdown, היסטוריית אחורה/קדימה, רשימת קבצים אחרונים וגרירה ושחרור.
- **ייצוא ל-PDF, ל-Word ‏(.docx) ול-HTML** עם <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>. העברית נשארת מימין לשמאל גם ב-Word, והנוסחאות הופכות למשוואות Word שניתנות לעריכה. **העתקה כטקסט מעוצב** (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>) להדבקת המסמך המעוצב ב-Gmail, ב-Outlook, ב-Word או ב-Google Docs. **הדפסה** עם <kbd>Ctrl</kbd>+<kbd>P</kbd>.
- **בטוח.** קובצי Markdown לא יכולים להריץ סקריפטים.

## התקנה

| קובץ | מה זה |
|---|---|
| `MadReader-1.2.0-setup.exe` | תוכנית התקנה (בעברית או באנגלית). ההתקנה היא למשתמש הנוכחי ולא צריך הרשאות מנהל. |
| `MadReader-1.2.0-portable.zip` | קובץ ההפעלה בלבד. אפשר להריץ אותו מכל מקום וללחוץ **Install** במסך הפתיחה כדי להתקין. |

**דרישות:** Windows 10 או 11 (64 סיביות), ו-WebView2 Runtime, שכבר מותקן ב-Windows 11 וב-Windows 10 מעודכן.

### הגדרה כאפליקציית ברירת מחדל לקובצי `.md`

ב-Windows רק המשתמש יכול לבחור אפליקציות ברירת מחדל, ולכן נדרשת לחיצה אחת בהגדרות:

1. מתקינים את Mad Reader, בתוכנית ההתקנה או בכפתור **Install** שבתוך האפליקציה.
2. לוחצים **Set as default** במסך הפתיחה. אפשר גם דרך *⋯ ← Default app settings…*, או בתיבת הסימון שבסוף ההתקנה.
3. בחלון ההגדרות שנפתח בוחרים ב-**Mad Reader** עבור `.md`.

אפשרות נוספת: לחיצה ימנית על קובץ `.md` ← **פתח באמצעות** ← **בחר אפליקציה אחרת** ← **Mad Reader** ← **תמיד**.

| חיפוש | <kbd>Ctrl</kbd>+<kbd>F</kbd> |
| תוכן עניינים | <kbd>Ctrl</kbd>+<kbd>B</kbd> |
| כיוון טקסט: אוטומטי ← ימין לשמאל ← שמאל לימין | <kbd>Ctrl</kbd>+<kbd>D</kbd> |

| אחורה / קדימה | <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd> |

| פתיחה בעורך | <kbd>Ctrl</kbd>+<kbd>E</kbd> |
| כל הקיצורים | <kbd>F1</kbd> |

## הסרה

*הגדרות ← אפליקציות ← אפליקציות מותקנות ← Mad Reader ← הסר התקנה*. ההסרה מוחקת גם את רישום סוגי הקבצים ואת ההגדרות.
